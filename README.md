## 💡 A ideia por trás do projeto

Pequenos negócios como barbearias muitas vezes perdem clientes por não terem presença digital. O dono depende do boca a boca, de grupos no WhatsApp ou de perfis informais no Instagram — sem uma vitrine profissional que transmita credibilidade.

O **InkDrop Barbearia** foi criado para resolver exatamente isso: uma landing page que transforma o visual digital de um negócio local em algo que compete com marcas grandes.

> *"Qualquer negócio merece um site bonito — independente do tamanho."*

---

## 🎯 Qual dor ele resolve?

| Problema do cliente | O que a landing page entrega |
|---|---|
| "Não sei o que vocês oferecem" | Seção clara de serviços e preços |
| "Qual o horário de funcionamento?" | Informações visíveis na página |
| "Como entro em contato?" | Links diretos para redes sociais |
| "Parece amador" | Design moderno que transmite confiança |
| "Não funciona bem no celular" | Layout 100% responsivo |

---

## ✨ Funcionalidades

- 🎨 **Design elegante e moderno** com paleta escura e dourada
- 💇 **Seção de serviços** com descrição e preços
- 📍 **Localização e horário** de atendimento
- 📱 **Totalmente responsivo** — perfeito em celular, tablet e desktop
- 🔗 **Integração com redes sociais** — Instagram, WhatsApp
- ⚡ **Performance otimizada** — carregamento rápido

---

## 🧠 O que aprendi construindo isso

- **SCSS na prática** — variáveis, mixins, nesting e como isso torna o CSS muito mais organizado e reutilizável
- **Componentização com partials** — dividir o HTML em seções separadas (`header.html`, `services.html`) para manter o código limpo
- **Responsividade com media queries** — adaptar layouts para diferentes tamanhos de tela sem frameworks
- **Deploy na Vercel** — publicar um projeto estático gratuitamente com domínio próprio

## 🗂️ Estrutura do projeto

```
Landing-Page-Barbearia/
├── assets/
│   └── images/             → Fotos e ícones da página
├── partials/               → Seções reutilizáveis do HTML
├── index.html              → Página principal
├── style.scss              → Estilos em SCSS
├── style.css               → CSS compilado
└── index.js                → Scripts de interatividade
```

## 🚀 Como rodar localmente

```bash
# Clone o repositório
git clone https://github.com/GabrielNascimentoDev/Landing-Page---Barbearia-.git
cd Landing-Page---Barbearia-

# Abra direto no navegador
open index.html

# Ou, para compilar o SCSS automaticamente:
npm install
npm run watch
```
